# Задание 1 — Простой транслятор Python → Java

## Цель работы

Создать базовый транслятор,
который автоматически переводит
простейшие конструкции Python в Java.

---

## Что используется в коде

### 1. Модуль `ast`

```python
import ast
```

Модуль `ast` используется для построения
Abstract Syntax Tree — абстрактного синтаксического дерева.

AST позволяет представить программу
в виде структуры объектов Python.

Например:

```python
x = 10
```

представляется как узел:
- Assign
- Name
- Constant

---

### 2. Класс `PythonToJavaTranslator`

```python
class PythonToJavaTranslator(ast.NodeVisitor):
```

Класс наследуется от `ast.NodeVisitor`.

Это позволяет обходить AST-дерево
и автоматически вызывать методы:

- `visit_Assign`
- `visit_If`
- `visit_While`
- `visit_BinOp`
- и другие

для каждого типа узла.

---

### 3. Метод `translate`

```python
tree = ast.parse(code)
```

Метод:
1. получает Python-код
2. преобразует его в AST
3. запускает обход дерева
4. генерирует Java-код

Также формируется структура Java-класса:

```java
public class Main {
    public static void main(String[] args) {
    }
}
```

---

### 4. Обработка переменных

```python
def visit_Assign(self, node):
```

Метод:
- получает имя переменной
- получает значение
- создаёт Java-объявление

Пример:

Python:
```python
x = 5
```

Java:
```java
int x = 5;
```

Используется множество:

```python
self.variables = set()
```

чтобы не объявлять переменную повторно.

---

### 5. Арифметические операции

```python
def visit_BinOp(self, node):
```

Обрабатываются операции:
- `+`
- `-`
- `*`
- `/`
- `%`

Используется словарь операторов:

```python
operators = {
    ast.Add: "+",
    ast.Sub: "-",
    ast.Mult: "*"
}
```

---

### 6. Условные конструкции

```python
def visit_If(self, node):
```

Python:

```python
if x < y:
```

преобразуется в:

```java
if (x < y) {
}
```

---

### 7. Циклы

```python
def visit_While(self, node):
```

Python:

```python
while x < 10:
```

Java:

```java
while (x < 10) {
}
```

---

### 8. Вывод в консоль

```python
print(x)
```

переводится в:

```java
System.out.println(x);
```

через метод:

```python
visit_Call()
```

---

## Результат задания

Реализован простой транслятор,
поддерживающий:
- переменные
- арифметику
- условия
- циклы
- вывод данных

# Задание 2 — Транслятор программы вычисления факториала

## Цель работы

Создать программу вычисления факториала,
которая автоматически переводится
из Python в Java.

---

## Что используется в коде

### 1. Цикл `while`

```python
while n > 1:
```

Используется для вычисления факториала.

Алгоритм:
1. число уменьшается
2. результат умножается
3. цикл продолжается до 1

---

### 2. Арифметические операции

```python
fact = fact * n
n = n - 1
```

Транслятор преобразует операции
в Java-эквиваленты.

---

### 3. Сравнения

```python
n > 1
```

обрабатываются методом:

```python
visit_Compare()
```

Поддерживаются:
- `<`
- `>`
- `==`

---

### 4. Генерация Java-кода

На выходе формируется:

```java
while (n > 1) {
    fact = fact * n;
    n = n - 1;
}
```

---

### 5. Сохранение результата

```python
with open("Main.java", "w") as f:
```

Сгенерированный Java-код
автоматически сохраняется в файл.

---

## Результат задания

Реализована:
- автоматическая генерация Java-кода
- поддержка циклов
- поддержка арифметики
- вычисление факториала

---

# Задание 3 — Транслятор математических функций

## Цель работы

Создать расширенный транслятор
с поддержкой:
- функций
- рекурсии
- математических операций

---

## Что используется в коде

### 1. Поддержка функций

```python
def factorial(n):
```

обрабатывается методом:

```python
visit_FunctionDef()
```

Генерируется Java-метод:

```java
public static int factorial(int n)
```

---

### 2. Поддержка аргументов функций

```python
for arg in node.args.args:
```

Все аргументы автоматически
преобразуются в параметры Java.

---

### 3. Возврат значения

```python
return n
```

обрабатывается методом:

```python
visit_Return()
```

и преобразуется в:

```java
return n;
```

---

### 4. Рекурсия

Поддерживаются рекурсивные вызовы:

```python
factorial(n - 1)
```

и

```python
fibonacci(n - 1)
```

Транслятор корректно генерирует
рекурсивные Java-методы.

---

### 5. Поддержка `if / else`

Python:

```python
if n == 0:
```

Java:

```java
if (n == 0) {
}
else {
}
```

---

### 6. Возведение в степень

Python:

```python
a ** b
```

преобразуется в:

```java
Math.pow(a, b)
```

через:

```python
if isinstance(node.op, ast.Pow):
```

---

### 7. Поддержка функций

Реализована генерация:
- factorial
- fibonacci
- power

---

Реализован расширенный транслятор,

- функции
- рекурсию
- математические операции
- условные конструкции
- генерацию Java-методов

# Принцип работы транслятора

1. Python-код разбирается через `ast.parse()`
2. Создаётся AST-дерево
3. Выполняется обход дерева
4. Для каждого узла вызывается `visit_*`
5. Формируется Java-код
6. Код сохраняется в `Main.java`
