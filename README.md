# Задание 4 — Портирование файловых операций Windows API → Linux API


## Описание

В задании реализовано портирование файловых операций с Windows API на Linux API.

Были заменены следующие функции:

| Windows API | Linux API |
|---|---|
| `CreateFile` | `open` |
| `ReadFile` | `read` |
| `CloseHandle` | `close` |

Программа открывает текстовый файл, считывает его содержимое и выводит данные в терминал.


---

## Что используется в коде

### Заголовочные файлы

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
```

Используются для:

- `stdio.h` — функции вывода (`printf`)
- `fcntl.h` — работа с файлами (`open`)
- `unistd.h` — системные вызовы Linux (`read`, `close`)

---

### Работа с файловым дескриптором

```c
int file;
```

В Linux файл открывается не через объект, а через файловый дескриптор — число, которое идентифицирует открытый файл.

---

### Открытие файла

```c
file = open("test.txt", O_RDONLY);
```

Используется системный вызов `open`.

Флаг:

```c
O_RDONLY
```

означает открытие файла только для чтения.

---

### Проверка ошибок

```c
if (file < 0)
```

Если файл не открылся — программа выводит сообщение об ошибке.

---

### Чтение файла

```c
bytesRead = read(file, buffer, sizeof(buffer) - 1);
```

Функция `read`:

- читает данные из файла
- сохраняет их в массив `buffer`
- возвращает количество прочитанных байт

---

### Завершение строки

```c
buffer[bytesRead] = '\0';
```

Добавляется символ конца строки для корректного вывода текста.

---

### Закрытие файла

```c
close(file);
```

Освобождает системный ресурс.

---

## Функциональность

Программа:

- открывает файл
- читает содержимое
- выводит текст в терминал
- корректно закрывает файл
- обрабатывает ошибки открытия и чтения

# Задание 5 — Безопасная работа с указателями и памятью


## Описание

В задании реализованы примеры безопасной работы с динамической памятью в языке C.

Программа демонстрирует:

- выделение памяти через `malloc`
- проверку указателей на `NULL`
- освобождение памяти через `free`
- защиту от выхода за границы массива
- работу со строками
- безопасную работу с файлами

Основная цель задания — изучение принципов управления памятью и предотвращение типичных ошибок языка C.


---

## Что используется в коде

### Заголовочные файлы

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

Используются для:

- `stdio.h` — вывод информации
- `stdlib.h` — работа с памятью (`malloc`, `free`)
- `string.h` — работа со строками (`strcpy`)

---

## 1. Работа с одиночным указателем

### Выделение памяти

```c
ptr = (int *)malloc(sizeof(int));
```

`malloc` выделяет память под одну переменную типа `int`.

---

### Проверка на NULL

```c
if (ptr == NULL)
```

Проверяется успешность выделения памяти.

---

### Запись значения

```c
*ptr = 42;
```

Оператор `*` используется для доступа к значению по адресу указателя.

---

### Освобождение памяти

```c
free(ptr);
ptr = NULL;
```

После освобождения памяти указатель обнуляется для защиты от висячих указателей.

---

## 2. Работа с массивом

### Выделение памяти под массив

```c
int *arr = (int *)malloc(5 * sizeof(int));
```

Создаётся динамический массив из 5 элементов.

---

### Заполнение массива

```c
arr[i] = i * 10;
```

Элементы массива заполняются значениями.

---

### Освобождение памяти

```c
free(arr);
arr = NULL;
```

Память очищается после завершения работы.

---

## 3. Проверка границ массива

### Защита от выхода за границы

```c
if (index < 0 || index >= size)
```

Проверяется корректность индекса.

Это предотвращает:

- segmentation fault
- чтение чужой памяти
- повреждение данных

---

## 4. Работа со строками

### Выделение памяти под строку

```c
char *str = (char *)malloc(50 * sizeof(char));
```

Создаётся динамическая строка.

---

### Копирование строки

```c
strcpy(str, "Safe pointer demo in C");
```

Функция `strcpy` копирует текст в выделенную память.

---

## 5. Работа с файлами

### Открытие файла

```c
FILE *file = fopen("test.txt", "w");
```

Создаётся файловый поток.

---

### Запись данных

```c
fprintf(file, "C safe pointer demo\n");
```

Текст записывается в файл.

---

### Закрытие файла

```c
fclose(file);
file = NULL;
```

Файл корректно закрывается.

---

## Функциональность программы

Программа демонстрирует:

- безопасное выделение памяти
- проверку указателей
- освобождение ресурсов
- защиту от ошибок работы с памятью
- безопасную работу с файлами

# Задание 6 — Параллельные вычисления с использованием pthread


## Описание

В задании реализована программа многопоточного вычисления суммы элементов массива.

Для параллельного выполнения используются POSIX Threads (`pthread`).

Массив делится между несколькими потоками, каждый поток вычисляет сумму своей части массива, после чего результаты объединяются.


---

## Что используется в коде

### Заголовочные файлы

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
```

Используются для:

- `stdio.h` — вывод данных
- `stdlib.h` — стандартные функции
- `pthread.h` — работа с потоками POSIX

---

## Глобальные массивы

```c
long long array[SIZE];
long long partial_sum[THREADS];
```

- `array` хранит данные
- `partial_sum` хранит результаты каждого потока

---

## Структура данных потока

```c
typedef struct {
    int start;
    int end;
    int index;
} ThreadData;
```

Структура содержит:

- начало диапазона
- конец диапазона
- индекс потока

---

## Функция потока

```c
void* sum_part(void* arg)
```

Каждый поток:

- получает диапазон массива
- вычисляет сумму своей части
- сохраняет результат

---

## Создание потоков

```c
pthread_create(&threads[i], NULL, sum_part, &tdata[i]);
```

Создаются параллельные потоки выполнения.

---

## Синхронизация потоков

```c
pthread_join(threads[i], NULL);
```

Главный поток ожидает завершения всех дочерних потоков.

---

## Суммирование результатов

```c
total += partial_sum[i];
```

После завершения потоков вычисляется итоговая сумма.

---

## Функциональность программы

Программа:

- создаёт массив
- делит задачу между потоками
- выполняет параллельные вычисления
- объединяет результаты
- выводит итоговую сумму
