Практическая работа по теме **"Языковые конверсии и кроссплатформенные приложения"**.

## Задания


### Задание 1 — Простой транслятор Python → Java

Программа автоматически переводит простой код с Python на Java.

Поддерживаются:
- переменные
- арифметические операции
- `if`
- `while`
- `print()`

Пример:

Python:
```python
x = 10
y = 20

if x < y:
    print(x + y)
```

Java:
```java
int x = 10;
int y = 20;

if (x < y) {
    System.out.println(x + y);
}
```

### Задание 3 — Транслятор математических функций

Реализован расширенный транслятор Python → Java
для математических функций.

Поддерживаются:
- функции `def`
- рекурсия
- `if / else`
- операции:
  - `+`
  - `-`
  - `*`
  - `/`
  - `**`
- функции:
  - `factorial`
  - `fibonacci`
  - `power`

Пример:

Python:
```python
def power(a, b):
    return a ** b
```

Java:
```java
public static int power(int a, int b) {
    return ((int)Math.pow(a, b));
}
```

## Принцип работы транслятора

1. Python-код разбирается в AST-дерево
2. Выполняется анализ синтаксических конструкций
3. Генерируется эквивалентный Java-код
4. Результат сохраняется в файл `Main.java`
