Практическая работа по теме **"Портирование ПО и работа с системными вызовами"**.

# Задание 1 — PID процесса (POSIX)

## Описание

Программа получает:
- PID текущего процесса (`getpid`)
- PID родительского процесса (`getppid`)

## Сборка и запуск

```bash
cd task1
gcc main.c -o program
./program
```


## Результат

Выводит идентификаторы процессов в терминал.

# Задание 2 — Работа с файлами (MINIX 3 / POSIX)

## Описание

Программа:
- открывает файл через `open()`
- читает через `read()`
- выводит через `write()`
- закрывает через `close()`

Также используется Makefile для автоматизации сборки.

---

## Файлы

- `main.c` — программа
- `Makefile` — сборка проекта
- `test.txt` — входной файл
- `custom.txt` — дополнительный файл

---

## Сборка

```bash
cd task2
make
```

---

## Запуск

```bash
make run
```

или

```bash
./program
```

---

## Очистка

```bash
make clean
```
