# Портирование ПО. Рабочая тетрадь 2. Задания 1-2-3. Ибраимов Д.Э ПИМО-01-25


## Описание

Практическая работа по теме **"Портирование программного обеспечения и работа с памятью/потоками"**.

В рамках работы реализованы:
- портирование Windows API → Linux API (файловые операции)
- безопасная работа с указателями и памятью
- параллельные вычисления с использованием потоков (pthread)

## Задание 1 — Портирование файловых операций (Windows → Linux)

### Описание

Программа демонстрирует замену Windows API:

- `CreateFile` → `open`
- `ReadFile` → `read`
- `CloseHandle` → `close`

### Функциональность

- открытие файла
- чтение содержимого
- вывод в терминал
- корректное закрытие файла

### Файлы

```
first/main.c
first/test.txt
```

---

### Пример test.txt

```text
Hello from file
Line 2
Line 3
```

---

### Запуск

```bash
cd first
gcc main.c -o program
./program
```

## Задание 2 — Безопасная работа с указателями

### Описание

Программа демонстрирует:

- выделение динамической памяти (`malloc`)
- проверку `NULL`
- использование указателей
- освобождение памяти (`free`)
- защиту от висячих указателей

### Функциональность

- работа с одиночным указателем
- работа с массивами
- проверка границ массива
- работа со строками
- работа с файлами

### Файлы

```
second/main.c
```

---

### Запуск

```bash
cd second
gcc main.c -o program
./program
```


---

## Задание 3 — Параллельные вычисления (pthread)

### Описание

Программа демонстрирует:

- разделение массива на части
- параллельное выполнение задач
- использование потоков (`pthread`)
- объединение результатов

### Функциональность

- создание потоков
- распределение задач
- вычисление суммы массива
- синхронизация через `pthread_join`

### Файлы

```
third/main.c
```

---

### Запуск

```bash
cd third
gcc main.c -o program -pthread
./program
```
