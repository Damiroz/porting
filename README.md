# Задание 1 — Получение PID процесса через POSIX


## Описание

Программа получает информацию о текущем процессе и его родительском процессе с использованием POSIX-функций:

- `getpid()` — PID текущего процесса
- `getppid()` — PID родительского процесса

Программа демонстрирует основы управления процессами в UNIX/Linux системах.


---

# Что используется в коде


## Заголовочные файлы

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
```

Используются для:

- `stdio.h` — функции ввода/вывода (`printf`)
- `unistd.h` — POSIX API (`getpid`, `getppid`)
- `sys/types.h` — тип данных `pid_t`

---

## Тип `pid_t`

```c
pid_t pid;
pid_t ppid;
```

`pid_t` — специальный тип данных для хранения идентификаторов процессов.

---

## Получение PID текущего процесса

```c
pid = getpid();
```

Функция возвращает:

- уникальный идентификатор текущего процесса

---

## Получение PID родительского процесса

```c
ppid = getppid();
```

Функция возвращает:

- PID процесса, который запустил текущую программу

---

## Проверка ошибок

```c
if (pid < 0)
```

Проверяется успешность получения идентификатора процесса.

---

## Вывод информации

```c
printf("Current PID : %d\n", pid);
printf("Parent PID  : %d\n", ppid);
```

Информация выводится в терминал.

---

# Функциональность программы

Программа:

- получает PID текущего процесса
- получает PID родительского процесса
- выводит данные в терминал
- выполняет базовую проверку ошибок

# Задание 2 — Работа с файлами через POSIX API


## Описание

В задании реализована программа для работы с файлами через низкоуровневые системные вызовы POSIX.

Программа:

- открывает файл
- читает содержимое
- выводит данные в терминал
- закрывает файл

Работа выполняется через файловые дескрипторы без использования стандартных потоков `FILE*`.


---

# Что используется в коде


## Заголовочные файлы

```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
```

Используются для:

- `stdio.h` — вывод ошибок
- `fcntl.h` — функции работы с файлами (`open`)
- `unistd.h` — системные вызовы (`read`, `write`, `close`)

---

## Буфер для чтения

```c
#define BUFFER_SIZE 128
```

Определяется размер буфера для чтения файла.

---

## Файловый дескриптор

```c
int fd;
```

Файл открывается через файловый дескриптор.

---

## Открытие файла

```c
fd = open("test.txt", O_RDONLY);
```

Используется системный вызов `open`.

Флаг:

```c
O_RDONLY
```

означает открытие файла только для чтения.

---

## Проверка ошибок

```c
if (fd < 0)
```

Если файл не открылся — выводится сообщение об ошибке.

---

## Чтение файла

```c
while ((bytesRead = read(fd, buffer, BUFFER_SIZE)) > 0)
```

Функция `read`:

- считывает данные из файла
- сохраняет их в буфер
- возвращает количество прочитанных байт

Чтение выполняется циклически до конца файла.

---

## Вывод данных

```c
write(1, buffer, bytesRead);
```

Используется системный вызов `write`.

Число:

```c
1
```

обозначает стандартный поток вывода (`stdout`).

---

## Закрытие файла

```c
close(fd);
```

Освобождается файловый дескриптор.

---

# Функциональность программы

Программа:

- открывает файл
- считывает данные блоками
- выводит содержимое в терминал
- обрабатывает ошибки
- корректно закрывает файл
